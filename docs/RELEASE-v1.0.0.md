**月薪喵 · Yuexinmiao Codex Pet**

首个公开版本，由 [@miroxsy-oss](https://github.com/miroxsy-oss) 整理、适配与维护。喜欢的话欢迎给仓库一个 Star！

The first public release, curated, adapted, and maintained by [@miroxsy-oss](https://github.com/miroxsy-oss). If you enjoy it, a Star is welcome!

## 安装 · Installation

- 下载并解压 `yuexinmiao-codex-pet-v1.0.0.zip`，阅读 README.md 和 docs/INSTALL.md。<br>
  Download and extract `yuexinmiao-codex-pet-v1.0.0.zip`, then read README.md and docs/INSTALL.md.
- 桌面 Codex：运行安装脚本，再在宠物设置中选择月薪喵。<br>
  Desktop Codex: run the installer, then select Yuexinmiao in pet settings.
- 网页／手机 Work：通过 ChatGPT 官方宠物设置上传 `dist/yuexinmiao-selected/spritesheet.webp` 并选中；手机使用相同账号和工作区。具备已授权操作能力的 Codex 可按教程协助完成。<br>
  Web/mobile Work: upload `dist/yuexinmiao-selected/spritesheet.webp` through ChatGPT’s official pet settings and select it. Use the same account and workspace on mobile. Codex with authorized tools can help follow the guide.
- 附件也提供单独的 `spritesheet.webp`，可直接用于 Work 上传。<br>
  A standalone `spritesheet.webp` is also attached for direct Work upload.

## 内容与范围 · Contents and scope

包含九种动画状态、安装说明与脚本、预览和技术自检。兼容公开文档中的 v1 图集格式，不代表官方认证。播放器时序限制见审计说明。

Includes nine animation states, installation instructions and scripts, previews, and technical checks. Compatible with the documented v1 atlas format; this is not official certification. See the audit documentation for player timing limitations.

手机运行动画已实测，但未逐一验证全部九种状态。本版本为原九状态图集；手机处理中观察到的挠头动作，后来在 v1.1.0 的独立 Work 专用版中替换为捂鼻扇风。

Mobile running animation was tested, but not all nine states individually. This release contains the original nine-state atlas. The head-scratching animation observed during mobile processing was later replaced with fanning in the separate v1.1.0 Work edition.
